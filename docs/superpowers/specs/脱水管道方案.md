LLM-Brain OS 动态召回脱水管道（Context Dehydration Pipeline）技术方案1. 方案背景与核心痛点在 LLM-Brain OS 的 L4 检索流（brain-query）中，BM25 算法或正则引擎召回的原始 Markdown 笔记直接拼接进 Claude 上下文时，暴露出三大核心工程痛点：字符水分与费用暴增：原始笔记中包含大量的 YAML FrontMatter、HTML 注释、行尾死空格以及动辄数百行的底层脚本或运行日志，直接烧穿 Claude 上下文空间，单次 API 响应延迟与计费激增。盲目 Chunk 导致知识断裂：传统的按行数或固定窗口截断的 Chunk 方案，极易将技术笔记中跨段落的上下文依赖（如配置项定义与函数调用）切碎，导致大模型产生严重幻觉。全局语义丢失（迷失在中间）：裁剪后的代码块或文本段落若丢失了上一级的父标题层级（H1/H2），Claude 无法识别该 Chunk 属于哪个具体项目或业务模块，丧失全局推理能力。2. 总体架构与生态位本方案在 L4 检索层（输出端） 与 L5 智能 Skill 层（输入端） 之间筑起一道 “Token 脱水堤坝”。数据流不破坏本地 .md 源码，仅在内存中作为过滤管道（Middleware）运行： [L4: bm25_search / rg_body_search 召回原始 MD 列表及命中行号]

3. 核心技术模块设计3.1 实体防御：双链 Token 原子化占位符逻辑：rtk 在开启极度压缩时会打碎符号与缩进。在压榨前，用正则将双链 [[stem]] 提取并替换为高纯度占位符 __BRAIN_LINK_XXX__。压榨完成后再行缝合，保证第二大脑的网状拓扑语义 100% 完好。3.2 结构防御：大纲树感知裁剪与最小单元保护代码块保护：若检索命中了 ``` 内部的任意一行，禁止手操硬切，必须将整个代码块区间完整保留，交由 rtk 进行安全坍缩。大纲块保护：以命中行最近的标题（###）开始，到下一个同级或高级标题结束之间的所有文本，视为一个不可分割的知识点段落。3.3 路径继承：面包屑语义注入（Breadcrumb Injection）逻辑：不加载父标题下的冗余正文，仅抽取 H1、H2 的标题文本，以 [📍 Context Scope: Root > H1 > H2] 的扁平化格式强行注入 Chunk 顶部。不到 20 字节，即可赋予 Claude 完美的全局项目感知力。3.4 物理压榨：基于 rtk (Rust Token Killer) 的动态路由策略：针对大文本与代码实施条件路由。体积 \(<5KB\) 的纯卡片笔记仅做正则去噪；体积 \(\ge 5KB\) 且含代码块的文档，调用本地 rtk read -l aggressive 命令，剔除函数具体实现，仅保留函数签名与核心接口。4. 核心工程实现 (context_dehydrator.py)以下是过滤管道的完整 Python 实现，集成了双链防御、多级标题继承、感知裁剪与 rtk 压榨流。单次线性扫描，性能损耗 \(<5\text{ms}\)：pythonimport re
import subprocess
import tempfile
import os

def dehydrate_context(raw_md: str, hit_lines: list[int], file_stem: str) -> str:
    """
    LLM-Brain OS 上下文脱水核心管道
    """
    if not raw_md.strip():
        return ""
        
    lines = raw_md.split("\n")
    total_lines = len(lines)
    
    # 1. 实体防御：提取并保护 [[stem]] 双链，防止被 rtk 误杀
    link_pattern = r"\[\[(.*?)\]\]"
    links_cache = re.findall(link_pattern, raw_md)
    
    # 用占位符重写正文
    placeholder_md = raw_md
    for idx, link_text in enumerate(links_cache):
        placeholder_md = placeholder_md.replace(f"[[{link_text}]]", f"__BRAIN_LINK_{idx}__")
    p_lines = placeholder_md.split("\n")

    # 2. 结构树分析：建立标题大纲栈快照
    line_hierarchies = []
    current_stack = {1: None, 2: None, 3: None}
    code_block_ranges = []
    in_code_block = False
    start_code_idx = 0
    
    for idx, line in enumerate(p_lines):
        stripped = line.strip()
        # 记录代码块边界
        if stripped.startswith("```"):
            if not in_code_block:
                in_code_block = True
                start_code_idx = idx
            else:
                in_code_block = False
                code_block_ranges.append((start_code_idx, idx))
                
        # 匹配标题行并剥离 OS 大纲树权重标记
        title_match = re.match(r"^(#{1,3})\s+(.*?)\$", stripped)
        if title_match:
            level = len(title_match.group(1))
            pure_title = title_match.group(2).split("—")[0].strip()
            current_stack[level] = pure_title
            for l in range(level + 1, 4):
                current_stack[l] = None
                
        line_hierarchies.append(current_stack.copy())

    # 3. 激活掩码：顺着语法纹理提取不可分割原子块
    keep_mask = [False] * total_lines
    for hit_line in hit_lines:
        actual_idx = hit_line - 1
        if not (0 <= actual_idx < total_lines):
            continue
            
        # 判定是否属于代码块原子
        in_code = False
        for start, end in code_block_ranges:
            if start <= actual_idx <= end:
                for k in range(start, end + 1):
                    keep_mask[k] = True
                in_code = True
                break
                
        # 判定为普通大纲段落原子
        if not in_code:
            start_bound = actual_idx
            for u in range(actual_idx, -1, -1):
                start_bound = u
                if p_lines[u].strip().startswith("#"):
                    break
            end_bound = actual_idx
            for d in range(actual_idx, total_lines):
                end_bound = d
                if p_lines[d].strip().startswith("#") and d > actual_idx:
                    end_bound = d - 1
                    break
            for k in range(start_bound, end_bound + 1):
                keep_mask[k] = True

    # 4. 组装 Chunk 并动态注入多级继承路径（面包屑）
    sliced_segments = []
    last_hierarchy_str = ""
    in_chunk_group = False

    for idx, keep in enumerate(keep_mask):
        if keep:
            h_dict = line_hierarchies[idx]
            path_nodes = [file_stem]
            for l in [1, 2, 3]:
                if h_dict.get(l):
                    path_nodes.append(h_dict[l])
            current_hierarchy_str = " ➔ ".join(path_nodes)

            if current_hierarchy_str != last_hierarchy_str or not in_chunk_group:
                sliced_segments.append(f"\n[📍 Context Scope: {current_hierarchy_str}]")
                last_hierarchy_str = current_hierarchy_str
                in_chunk_group = True

            sliced_segments.append(p_lines[idx])
        else:
            if in_chunk_group:
                sliced_segments.append("\n// ... [Omitted lines for Token Saving] ...\n")
                in_chunk_group = False

    intermediate_text = "\n".join(sliced_segments)

    # 5. 物理压榨：调用 Rust rtk 提取代码块签名并清洗文本噪声
    # 动态条件路由：若切片文本中包含代码块，则通过 rtk 压榨
    if "```" in intermediate_text:
        with tempfile.NamedTemporaryFile(mode='w+', suffix='.md', delete=False) as tf:
            tf.write(intermediate_text)
            temp_path = tf.name
        try:
            cmd = ["rtk", "read", temp_path, "-l", "aggressive"]
            res = subprocess.run(cmd, capture_output=True, text=True, check=True)
            dehydrated_body = res.stdout
        finally:
            if os.path.exists(temp_path):
                os.remove(temp_path)
    else:
        # 纯文本去噪：清洗多余空行、行尾死空格、HTML注释
        text = re.sub(r"<!--.*?-->", "", intermediate_text, flags=re.DOTALL)
        text = re.sub(r"[ \t]+$", "", text, flags=re.MULTILINE)
        dehydrated_body = re.sub(r"\n{3,}", "\n\n", text)

    # 6. 还原实体：将占位符还原回原生态的 [[stem]] 双链
    final_output = dehydrated_body
    for idx, link_text in enumerate(links_cache):
        final_output = final_output.replace(f"__BRAIN_LINK_{idx}__", f"[[{link_text}]]")
        
    return final_output.strip()

    """
    recalled_results 内含: [{'content': raw_md, 'hit_lines': [...], 'stem': '...', 'score': 0.85}, ...]
    按照 Top-K 权重降序排列，超出预算执行强硬熔断。
    """
    assembled_chunks = []
    current_estimated_tokens = 0
    
    for item in recalled_results:
        # 1. 运行脱水管道
        pure_chunk = dehydrate_context(item['content'], item['hit_lines'], item['stem'])
        
        # 2. 粗略估算 Token (字符数 // 3.5 针对中英混合仓)
        chunk_tokens = len(pure_chunk) // 3.5
        if current_estimated_tokens + chunk_tokens > max_total_tokens:
            assembled_chunks.append("\n\n[⚠️ SYSTEM WARNING: Sub-topical documents truncated due to token limit budget.]")
            break
            
        assembled_chunks.append(pure_chunk)
        current_estimated_tokens += chunk_tokens
        
    return "\n\n=== SOURCE_DOCUMENT_BORDER ===\n".join(assembled_chunks)
