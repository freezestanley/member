# 全局记忆大脑

本项目将 member/member vault 升级为跨项目全局中央记忆大脑。所有 Claude Code 会话通过 ~/.claude/commands/ 中的指令访问统一知识库。

## 架构
- wiki/concepts/：全局通用概念
- wiki/projects/<项目名>/：项目专属知识
- scripts/bm25_search.py：BM25 检索，支持双目录
- scripts/memory_manager.py：衰减归档，支持双目录
