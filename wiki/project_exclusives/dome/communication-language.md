# dome 项目沟通语言规范

## 结论

dome 项目全程使用中文沟通，包括：代码注释、提交信息、文档、与 AI 助手的对话。

## 边界

- 代码标识符（变量名、函数名、类名）不受此约束，仍遵循英文命名惯例。
- 第三方库文档、英文报错信息引用时保留原文，解释用中文。

## 适用范围

- 所有 Claude / AI 助手的回复语言
- PR 描述、注释、设计文档
- 项目内部沟通记录
